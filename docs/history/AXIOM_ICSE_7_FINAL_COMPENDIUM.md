## 1. Executive Summary & Status

AXIOM ICSE 7 is an editorial-first middle school educational platform built exclusively for the **CISCE Class 7 Science and Mathematics curriculum**. 

### 🎯 Key Accomplishments
- **24 Comprehensive Lesson Units Shipped:** Every module is self-contained with formal 3-point/5-point definitions, rigorous derivations, stoichiometric chemical equations, and ICSE examiner marking criteria.
- **Master Dynamic Index Built:** Direct hyperlinking across all modules, subject badges (`⚛️ PHY`, `🧪 CHEM`, `🌿 BIO`), live search filtering, and an inline model problem drawer.
- **Empty Container Rule Enforced:** Any container or filter that returns 0 items cleanly displays:
  $$\text{\textit{nothing here}}$$
- **100% Warm Editorial Aesthetic:** Completely free of corporate SaaS templates, slate-gray cards, generic blue buttons, and crude vector/stick-figure SVGs.

## 4. 7-Agent Workforce Architecture & System Prompts

```text
                               ┌───────────────┐
                               │   CO-WORKER   │ (Lead & Validation Orchestrator)
                               └───────┬───────┘
                                       │
        ┌─────────────┬────────────────┼────────────────┬─────────────┐
        ▼             ▼                ▼                ▼             ▼
  ┌───────────┐ ┌───────────┐    ┌───────────┐    ┌───────────┐ ┌───────────┐
  │ SOURCErer │ │  SCRIBE   │    │   SPARK   │    │ SENTINEL  │ │ BLUEPRINT │
  │  (Truth)  │ │ (Prose)   │    │(Pedagogy) │    │  (Audit)  │ │  (Render) │
  └───────────┘ └───────────┘    └───────────┘    └───────────┘ └─────┬─────┘
                                                                      │
                                                                      ▼
                                                                ┌───────────┐
                                                                │   PRISM   │
                                                                │ (QA/A11y) │
                                                                └───────────┘
```

### Specialist System Summary
1. **CO-WORKER (Lead Orchestrator):** Routes pipeline execution, unblocks bottlenecks, validates final outputs against the Master Design Checklist, and returns failing pages with revision requests.
2. **the SOURCErer (Ground Truth):** Extracts canonical chapter boundaries, verifies physical constants ($\rho, g$), and generates structured JSON truth bundles.
3. **SCRIBE (Scientific Writer):** Converts truth bundles into dense, examinable prose, structured definitions, and LaTeX equations.
4. **SPARK (Pedagogy Architect):** Integrates physical analogies, multi-tier non-spoiling hint drawers (`<details>`), and "Give Scientific Reasons" questions.
5. **SENTINEL (Fact Auditor):** Zero-tolerance audit for chemical equation balancing, dimensional consistency, and Class 7 scope adherence.
6. **BLUEPRINT (UI Engineer):** Renders complete, semantic HTML5/CSS3 templates in the warm ivory palette with Newsreader typography.
7. **PRISM (Visual QA Inspector):** Audits text contrast ($\ge 7:1$ body, $\ge 16:1$ headers), line lengths (65–75 chars), accessibility, and scans for forbidden words.
