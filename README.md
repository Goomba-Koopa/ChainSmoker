Hello, welcome here, though we do not know how you got here. You're in the good company of people who want to improve this library of knowledge. This will remain free forever, or in other words, libre. The main objective of this project is to create an alternative to heavy textbooks into a web resource, the current focus is on Grade 7 ICSE, which we believe to be comprehensive enough to be appreciated as useful but not heavy; post ICSE, we shall try to expand. However, there is no board specification. History has been currently excluded from the repository as different people and organization claim different events, so we do not want to open that Pandora's box; additionally we do not want to fall prone to historical bias, though this may be changed.
