# AXIOM Mathematics Topic Coding Standard

Whenever generating, referencing, rendering, or linking Mathematics topics in AXIOM ICSE 7:
- **Topic Codes MUST strictly use the 4-letter prefix `MATH-XX`** (e.g., `MATH-01`, `MATH-02`, `MATH-03`, `MATH-04`, `MATH-05`, `MATH-06`, `MATH-07`, `MATH-08`).
- **NEVER use `MAT-XX`**. Using truncated 3-letter codes causes ambiguity with other testing standards and violates the user's explicit specification: *"math is math not mat"*.
- Ensure this is uniform across topic badges, index JSON objects, and `topic-nav` arrow labels.
