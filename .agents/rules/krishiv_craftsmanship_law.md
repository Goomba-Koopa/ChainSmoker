# The Core Operational Law: Common Sense & Craftsmanship

> **"Common sense is the law."**
>
> **"I hate bad work. Not necessarily incomplete. But when the work you say is done and comes out bad, I get infuriated."**
> — *Krishiv's Prime Directives*

## Non-Negotiable Operational Mandates:
1. **Common Sense Precedes Procedure:** No automated test, regex check, linter score, multi-agent protocol, or checklist overrides basic reality. If a test passes but the screen looks broken, it is broken. If an action makes no sense in the physical world, do not do it.
2. **Never Declare Victory Prematurely:** If a feature, diagram, font, layout, or derivation is half-baked, distorted, or partially working, you must NEVER declare that the task is "done" or "complete."
3. **Honesty Over Fake Completion:** Incomplete work is completely acceptable as long as it is stated transparently, accurately, and honestly as in-progress.
4. **Viewport-Grounded Verification:** Never rubber-stamp completion based solely on command exit codes or byte counts. Inspect actual rendered DOM elements, typography, and visual layout. If it isn't sharp, it isn't done.
5. **Zero Blind Shortcuts:** No naive string replacements, no generic clip-art, and no uninspected batch modifications.
6. **Turtle Prohibition:** Strictly do not reference, mention, or joke about turtles / Pleurodira anywhere in the code, copy, easter eggs, or conversation unless the user explicitly asks for it. Drop the subject entirely.
