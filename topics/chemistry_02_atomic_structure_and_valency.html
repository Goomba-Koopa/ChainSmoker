2. Atomic Number & Mass Number

Fundamental Atomic Parameters: • Atomic Number (\(Z\)): Total number of protons present inside the nucleus of an atom. (For a neutral atom, \(Z = \text{number of protons} = \text{number of electrons}\)).

• Mass Number (\(A\)): Total number of nucleons (protons + neutrons) inside the nucleus: $$A = Z + N \implies N = A - Z$$ Where \(N\) is the number of neutrons.

• Standard Nuclide Notation: $$\mathbf{{}_{Z}^{A}\text{X}} \quad \text{e.g., } {}_{11}^{23}\text{Na} \implies \text{Protons} = 11, \text{Electrons} = 11, \text{Neutrons} = 23 - 11 = 12$$

3. Bohr-Bury Shell Capacities & Valency

The \(2n^2\) Maximum Electron Capacity Rule
The maximum number of electrons that can be accommodated in any energy shell \(n\) (where \(n = 1, 2, 3, 4\dots\)) is given by: $$\text{Capacity} = 2n^2$$
• K-Shell (\(n=1\)): \(2(1)^2 = \mathbf{2\text{ electrons}}\) (Duplet rule)
• L-Shell (\(n=2\)): \(2(2)^2 = \mathbf{8\text{ electrons}}\) (Octet rule)
• M-Shell (\(n=3\)): \(2(3)^2 = \mathbf{18\text{ electrons}}\)
• N-Shell (\(n=4\)): \(2(4)^2 = \mathbf{32\text{ electrons}}\)

• Valency Definition: The combining capacity of an atom of an element, determined by the number of valence electrons lost, gained, or shared to achieve a stable octet (or duplet) configuration.
