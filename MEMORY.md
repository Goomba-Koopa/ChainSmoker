# Core Memory & User Axioms

## Krishiv's Prime Directives
> **"Common sense is the law."**
>
> **"I hate bad work. Not necessarily incomplete. But when the work you say is done and comes out bad, I get infuriated."**

### Operational Mandates:
1. **Common Sense Overrides Procedure:** No automated test, linter score, checklist, or agent protocol overrides physical reality. If the screen looks wrong, it is wrong. If an action makes no sense in the real world, do not do it.
2. **Never Declare Victory Prematurely:** If any part of a task is still in progress, half-baked, or visually/technically unverified, explicitly state that it is in progress. Do not claim it is "done".
3. **Quality Over False Completion:** Incomplete work is completely acceptable as long as it is transparently communicated. But claiming poor or broken work is complete is strictly forbidden.
4. **Rigorous Viewport Verification:** Every single font, line, layout element, formula, and SVG must be verified for sharpness, geometric precision, and correctness in the actual browser before presenting to the user.
5. **Turtle Prohibition:** Absolutely stop bringing up, joking about, or referencing the turtle / Pleurodira / taxidermy. Do not mention turtles anywhere in the project or conversation unless explicitly requested by the user.
